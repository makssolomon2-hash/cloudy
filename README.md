# ☁️ Cloudy

> A modern, fast and beautifully designed online messenger.

[Live Demo] · [GitHub] · [Report a Bug]

## ✨ Overview

Cloudy is a modern web-based messaging platform focused on
clean UI, smooth interactions and a fast user experience.

## 🚀 Features

- 💬 Real-time messaging
- 👤 User profiles
- 🔍 Conversation search
- 🔔 Notifications
- 🌓 Dark / Light mode
- 📱 Responsive design
- ⚡ Smooth animations
- 🔐 Authentication
